# Roadmap

This is an early macOS visual reference tool. These are directions, not delivery commitments.

Implemented in the current source: local import and deduplication, SQLite metadata, thumbnail generation, virtualized browsing, notes and categories, optional AI image analysis and text-based smart search. Legacy collection data remains supported in storage, while collection management is absent from the current UI.

Potential next steps:

- Refine the interface, onboarding and accessibility.
- Expand reproducible regression tests and document platform limitations.
- Explore browser capture with source attribution and user-controlled import.
- Investigate video and visual similarity search.
- Evaluate private sync only after defining access control and privacy requirements.

No cloud sync, browser extension, video analysis or third-party platform importer is currently shipped.
